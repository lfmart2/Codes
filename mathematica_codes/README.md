# Mathematica Codes (PhD Portfolio)

This folder is a **curated set of Mathematica notebooks** from my PhD and graduate research training.
It shows how I use Wolfram Mathematica to move from theory to reproducible computational results in condensed matter physics.

---

## What this folder demonstrates

- Practical implementation of **topological condensed matter** concepts.
- Combination of **symbolic derivations + numerical experiments**.
- Notebook-based workflows for **model validation, visualization, and interpretation**.
- Clear bridge between theoretical physics and computational prototyping.

---

## How to run

1. Open a notebook (`.nb`) in Wolfram Mathematica.
2. Run **Evaluation → Evaluate Notebook** (or execute section-by-section).
3. If modifying parameters, re-evaluate from top to bottom for consistent outputs.

---

## Suggested order for first-time visitors

1. Start with **`code_Wilson_loop.nb`** (topological methods).
2. Continue with **`SSHModel.nb`** (canonical tight-binding physics).
3. Review **`c_drawing_disclinations_c2_2.nb`** (geometric/topological insight).

## Wolfram Mathematica
Mathematica codes from previous projects and courses.

- **c_drawing_disclinations_c2_2:** This codes creates Topological disclinations and lattice singularities for a 2D square lattice. It also provides a code to generate higher order topological insulators lattices.
- **Code_Wilson_loop:** An easy example to calculate the Wilson Loop of the Quantum Spin Hall effect (QSH).
- **SSHModel:** An interesting idea to analytically calculate the SSH model wavefunctions with open boundary conditions (OBC) using the bulk solutions. Interesting observations of the surface states and its analytical edge localization.
- **Various_Models:** A compilation of topological systems (Tight-Binding Models) and its corresponding Wannier Centers and Wilson Loops.
